# 成电每日打卡（同学版）

每晚 21:05 自动完成「成电智慧学工」小程序的每日打卡。首次配置约 3 分钟，之后不用管。

## 三步上手

1. 把整个文件夹解压到**固定位置**（例如 `D:\成电打卡`），不要放 U 盘、不要放临时目录。
2. 双击 **`首次配置.bat`**：弹出二维码 → 用**本人微信**扫码并点「确认」→ 在列表里选你的打卡地点。
3. 完成。当晚 21:05 自动打卡，成功后**不打扰你**，失败才弹窗。

> 前置条件：你的微信已经在小程序「成电智慧学工」里绑定学号。

## 文件说明

| 文件 / 目录 | 说明 |
| --- | --- |
| `首次配置.bat` | 只有第一次用：扫码授权 + 选打卡点 + 注册每晚任务 |
| `演练.bat` | 只查询今天状态，**不提交**，可随时点 |
| `打卡.bat` | 立即手动打卡一次（20:00 之后才有意义） |
| `ledger.jsonl` | 每次运行的台账，排错看这个 |
| `wx-credentials.json.dpapi` | 微信授权凭据（Windows DPAPI 加密，只有本机本账户能解开） |
| `config.json` | 你的打卡坐标等配置 |
| `python/` + `vendor/` | 自带的 Python 与依赖，**不用另外安装任何东西** |

## 工作原理（一句话）

微信扫码授权拿到凭据 → 每次运行时现场换一个小程序会话 → 换取一次性打卡票据 → 用服务端给你的固定坐标提交 → 回读确认状态 → 写台账。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 二维码没自动打开 | 手动双击 `wx-qr.png` |
| 提示「还没有绑定学号」 | 先在小程序里完成学号绑定，再重新配置 |
| 微信里扫码后没反应 | 必须用**本人**微信，且小程序已登录过 |
| 晚上电脑关机/睡眠 | 任务会在开机联网后补跑（最晚 23:15）；超时就手动打 |
| 火绒/360 弹窗询问 | 点「允许」，并把本文件夹加入信任区 |
| 弹窗「打卡失败」 | 先在小程序里手动打一次，再把 `ledger.jsonl` 最后一行发给我 |

## 隐私与合规

- 凭据只保存在本机，用 Windows DPAPI 加密；换电脑或换 Windows 账户需要重新扫码。
- 工具不上传任何数据，只和你学校的服务器通信。
- **仅限本人使用**：票据与学号绑定，技术上也无法代他人打卡。
- 电脑需在 21:05 前后处于开机且联网状态（可以睡眠，唤醒后会补跑）。
